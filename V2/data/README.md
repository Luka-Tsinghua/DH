# V2 数据目录说明
# V2 Data Directory Guide

本目录用于保存 V2 的 raw source 登记、metadata、处理后数据和外部 authority 对照表。

This directory stores V2 raw source registration, metadata, processed data, and external authority crosswalks.

---

## 1. 目录结构 / Directory Structure

```text
data/
├── raw/
│   └── RAW_SOURCE_MANIFEST.csv      # 登记真实 raw source 路径 / registered real raw source paths
├── metadata/
│   └── documents_seed.csv           # 文献级 metadata / document-level metadata
├── processed/
│   ├── verified_excerpt_segments.jsonl
│   ├── sample_segments.jsonl
│   └── full_segments.jsonl          # 由 CLI 生成 / generated by CLI
└── external_authorities/
    └── authority_crosswalk_seed.csv # 外部 authority 对照 / external authority crosswalk
```

仓库根目录中的 `1674_坤輿圖說_WS.txt` 与 `1799_地球圖説_WS.txt` 是当前 V2 使用的真实 raw source。V2 不移动、不覆盖这两个原始文件，而是在 `RAW_SOURCE_MANIFEST.csv` 中登记它们。

The root-level `1674_坤輿圖說_WS.txt` and `1799_地球圖説_WS.txt` are the real raw sources currently used by V2. V2 does not move or overwrite these source files; it registers them in `RAW_SOURCE_MANIFEST.csv`.

---

## 2. raw / Raw Source Manifest

`raw/RAW_SOURCE_MANIFEST.csv` 记录：

`raw/RAW_SOURCE_MANIFEST.csv` records:

```text
document_id, raw_source_path, source_role, source_status, processing_note
```

运行以下命令检查登记路径是否真实存在：

Run the following command to verify that registered paths exist:

```bash
python V2/scripts/dh_v2.py validate-raw-sources
```

---

## 3. metadata / Metadata

`metadata/documents_seed.csv` 是文献级 metadata 的起点。

`metadata/documents_seed.csv` is the starting point for document-level metadata.

新增文献后，应运行：

After adding a new text, run:

```bash
python V2/scripts/dh_v2.py validate-documents
```

---

## 4. processed / Processed Data

`processed/verified_excerpt_segments.jsonl` 保存从真实仓库文本中人工整理出的摘录段落，适合用于 pilot case。

`processed/verified_excerpt_segments.jsonl` stores manually curated excerpt segments from real repository texts and is suitable for the pilot case.

`processed/full_segments.jsonl` 应由 CLI 从 `RAW_SOURCE_MANIFEST.csv` 中登记的完整 raw source 自动生成。

`processed/full_segments.jsonl` should be generated by the CLI from the complete raw sources registered in `RAW_SOURCE_MANIFEST.csv`.

```bash
python V2/scripts/dh_v2.py build-segments-from-raw
python V2/scripts/dh_v2.py validate-segments --segments data/processed/full_segments.jsonl
```

`processed/sample_segments.jsonl` 只保留为 smoke-test sample，不进入正式研究解释。

`processed/sample_segments.jsonl` is retained only as a smoke-test sample and should not enter formal research interpretation.

正式 segment 文件应使用 JSONL，每行至少包含：

Formal segment files should use JSONL, with each row containing at least:

```json
{"segment_id":"...","document_id":"...","segment_index":0,"text":"..."}
```

---

## 5. external_authorities / External Authorities

`external_authorities/authority_crosswalk_seed.csv` 用于记录本地人名、文献名、术语和外部数据库之间的候选或已验证对照。

`external_authorities/authority_crosswalk_seed.csv` records candidate or verified links between local persons, texts, terms, and external databases.

外部 authority 数据必须保留来源和授权说明。

External authority data must preserve source and license notes.
