# DH V2：明清西学文本与跨文化知识史长期项目

## 项目定位

DH V2 是一个面向文史学科的长期研究基础设施项目。它不是 V1 workshop 展示项目的增强版，也不是为了生成若干图表而存在的技术演示。

它的目标是建设一个可持续运行、可审计、可扩展的明清西学中文文献语料库，用于支持：

- 文献整理；
- OCR 与校勘；
- 术语追踪；
- 人名、地名、机构、书名、度量衡抽取；
- 知识命题抽取；
- 文本相似性与知识谱系研究；
- 传教士、清廷、士人之间的知识网络研究；
- 概念史、知识传播史、思想史和宗教史研究。

## 项目基本信念

1. 文史研究的核心仍然是材料、语境、证据链和解释。
2. 数据清洗不是技术杂活，而是文献学判断的一部分。
3. AI 与计算方法用于扩大材料控制能力，而不是替代学者判断。
4. 所有抽取结果必须能回溯到原文证据。
5. 原始数据、清洗规则、版本、外部数据库授权必须长期可审计。
6. 本项目应能持续多年运行，而不是服务于一次性展示。

## V1 / V2 关系

- V1：原始 workshop prototype。用于证明 OCR、ChatGPT Code Interpreter、CkipTagger 与 N-gram 的基本可行性。
- V2：长期项目。以材料控制、数据模型、外部 authority、版本治理和研究产出为核心。

V1 应冻结归档。V2 独立演进。

## 最低成熟度目标

V2 达到成熟可持续项目，至少需要具备：

- 稳定目录结构；
- 数据模型；
- metadata schema；
- external authority 策略；
- 数据授权与发布策略；
- 版本治理；
- 贡献规范；
- inventory 与 QC 脚本；
- 清洗与抽取 pipeline；
- release 机制；
- 长期 research roadmap；
- 明确的人工校验流程。
