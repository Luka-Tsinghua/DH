# V2 Method

V2 treats the repository as a reproducible research system rather than a display project.

Core layers:

1. raw source registration;
2. document metadata;
3. text segmentation;
4. controlled vocabulary;
5. KWIC;
6. candidate evidence;
7. candidate claims;
8. human review;
9. release manifest.

Generated rows are candidates. They require human review before being used as scholarly claims.

The current real sources are registered in `V2/data/raw/RAW_SOURCE_MANIFEST.csv`.
